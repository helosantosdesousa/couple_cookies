🍪 Website da Couple Cookies

Este é o código-fonte do website oficial da Couple Cookies, uma confeitaria especializada em cookies quentinhos e feitos na hora.

Visite o site oficial: [www.couplecookies.com.br](https://couplecookies.com.br)

✨ Tecnologias Utilizadas

O projeto é um website estático e responsivo construído com:

HTML5: Estrutura básica do site.

CSS3: Estilização e design personalizado.

JavaScript: Interatividade (como o carrossel de avaliações e a seção Cookietômetro).

Bootstrap 5.3: Framework para layout e responsividade.

Google Fonts & Fontes Locais: Tipografia única e marcante.

Bootstrap Icons: Conjunto de ícones vetoriais.


💻 Estrutura do Projeto

O repositório é organizado da seguinte forma (presumindo uma estrutura básica):

.
├── assets/
│   ├── imgs/           # Imagens, logos e ícones
│   └── fonts/          # Fontes personalizadas (@font-face)
├── css/
│   └── styles.css      # Todo o CSS principal do projeto (responsividade, cores, etc.)
├── script/
│   ├── containers.js   # Scripts de comportamento (se houver)
│   ├── avaliacoes.js   # Lógica do carrossel de avaliações
│   └── vendas.js       # Lógica para o Cookietômetro (contadores)
└── index.html          # Página principal do website
